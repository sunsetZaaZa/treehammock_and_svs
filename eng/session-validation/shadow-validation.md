Run `python3 eng/session-validation/rollout/rollout.py collect --input ABSOLUTE_JSONL --job-key ABSOLUTE_JOB_KEY --context ABSOLUTE_CONTEXT --output NEW_ABSOLUTE_REPORT` in an isolated owned job. Every input must be an owned, nonsymlink regular 0400/0600 file; output is created exclusively at 0600. Mount private input and key directories at 0700. The key is exactly 32 random bytes, unique per job, never an exported artifact or a long-lived correlation key. Acquire tokens through a private file descriptor or private mounted input, never arguments/environment/logs. The CLI disables its core dumps; operators must also isolate debugger/swap/host capture and retention. Python cannot promise heap zeroing. The key bytearray is overwritten on exit, and private raw paired captures in the supplied validation runner are deleted with its temporary directory.

Context is a closed object with version=1, scope (Synthetic, GoldenReference or StagingTrustedSample), old_source_sha256, svs_source_sha256 and an explicit replicas array of `svs-1` through `svs-8`. The two digests must differ and identify independently reviewed providers; differing strings alone do not prove provenance. The qualification signer must verify those providers and input acquisition. Each closed JSONL record has token; old and svs objects each containing decision and identity; replica; cache_hit; sql_reads; duration_us; writer_fence_us. Decision is Active, Unauthenticated, Forbidden or Unavailable. Active identity contains lowercase 32-hex account and family IDs, positive generation and protocol 2; other decisions require null identity. The operator producer must measure durations and writer pressure and truthfully classify cache hits; fabricated input cannot qualify itself.

The collector limits input to 8 MiB, 10,000 records, 16 KiB per record, tokens to 8192 ASCII bytes, eight replicas and bounded nonnegative integer counters. Unknown/duplicate fields, Boolean-as-number values and nonfinite numbers fail closed. It exports only a job-keyed HMAC-SHA256 fingerprint, decision codes, identity-equality Boolean, fixed replica labels and aggregate counters/latencies. Tokens and account/family IDs are compared privately and never exported. Shadow observations grant no sessions and never enter the request identity feature or cache admission. Collection reports remain CollectedUnqualified with native_acceptance NotRun, rights/readiness false.

All paths obey the same private-file requirements. Missing qualification blocks immediately. The policy example is deliberately unusable: source/key digests and performance budgets require independent operator review before use. The trusted signer must be independent of the submitting collector job and verify actual source, staging acquisition, native evidence and prior applied tier.

The exact packet bytes are signed, using detached Ed25519 verification through OpenSSL. The signer attests the meaning of these digests; the tool verifies signature, digest consistency and completeness, not the truth of a self-written report. Never sign invented fixture evidence with a production qualification key.
